# Отчёт: постобработка OCR паспорта РФ

## Подход

Скрипт на стандартной библиотеке Python принимает документ только при наличии всех десяти полей, достаточных confidence значениях, корректных форматах дат и идентификаторов, действительности паспорта на 01.10.2026 и согласованности ключевых полей с MRZ. Проверяются ФИО, дата рождения, пол, часть номера паспорта и окончание кода подразделения. Неуверенный текст не исправляется догадками: документ отклоняется.

## Проверка на размеченных данных

При текущих порогах скрипт принял 16 из 3000 документов полной обучающей выборки; ошибок среди этих 16 не было. Дополнительно используется воспроизводимое разбиение с seed 42: 75% fit / 25% holdout. На нём fit принял 10 из 2250 (0 ошибок), holdout — 6 из 750 (0 ошибок). Это малые выборки принятых документов. Порог был выбран после предварительного анализа всей обучающей выборки, поэтому это разбиение следует считать диагностическим, а не полностью независимой оценкой.

## Результат и прогноз для test

На 2000 тестовых записей сформирован ответ для каждой: принято 33, отклонено 1967. Прогноз — 0 ошибок среди 33 принятых, но тестовая разметка недоступна, поэтому этот прогноз не подтверждён. Правило отдаёт приоритет снижению риска ошибочного принятия ценой низкой доли принятых документов.

## Ограничения

OCR confidence не гарантирует точность, а ошибки в VIZ и MRZ могут совпасть. Проверка окончания кода подразделения опирается на формат именно предоставленного набора данных и требует повторной проверки при переносе на другие источники. Паспорт проверяется на дату 01.10.2026 по возрастным границам 20/45 лет и 90-дневному периоду замены.
